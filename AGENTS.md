# PerkScout maintenance

Resource facts are authored only in data/resources.json. README.md is generated by scripts/build.py; never hand-edit it. CONTRIBUTING.md owns the schema semantics and review policy. Do not create additional resource lists or mirror datasets. Keep public content in English and include providers regardless of country. Never include personal account details, secrets or local knowledge-base links. Verify claims with official sources; keep uncertain claims pending. Run python scripts/build.py --check before committing.
