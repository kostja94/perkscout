## How to read this list

Free access and signup conditions are independent. Ongoing free access can still require registration, have rate limits, or restrict eligible regions. Unknown means not confirmed, not unrestricted.

Verified means the core offer was reviewed in official material on the listed date; it does not mean we tested signup or API calls. Entries older than 90 days move to pending review when regenerated. Credits from different providers are not directly comparable. Read the details before enabling billing or paid fallbacks.

20 reviewed offers; 13 pending; 6 with no confirmed free offer; 1 retired. A provider may offer more than one distinct free route.

<a id="keenable"></a>

### Keenable Search API

- Eligibility: Create an organization and API key; no card needed for the free allowance.
- Overage: Returns 402 without credits. Optional auto top-up can charge immediately when enabled below its threshold; leave it off for a free-only budget.
- Notes: Resets on the organization creation day (last day in shorter months). 10 RPS per organization. Paid usage after the allowance is $4/1K; not a guaranteed performance or uptime claim. Credit prices can be organization-specific; read the returned usage rather than assuming every operation always costs one credit.
- Official sources: [Source 1](https://keenable.ai/pricing), [Source 2](https://docs.keenable.ai/credits)

<a id="keenable-keyless"></a>

### Keenable keyless access

- Eligibility: No API key or account; capacity shared by callers on the same public IP.
- Overage: Hourly limits apply; 429 responses include retry guidance.
- Notes: Anonymous access is separate from the account monthly grant and from paid x402 calls. Shared hosting shares the IP pool. HTTP, MCP and CLI can be tried without an account.
- Official sources: [Source 1](https://docs.keenable.ai/), [Source 2](https://keenable.ai/pricing)

<a id="search1"></a>

### Search1API

- Eligibility: Check provider signup and regional terms.
- Overage: Returns 402 when balance cannot cover a request. Auto top-up is optional and off by default.
- Notes: Basic search, news or crawl costs one credit; agentic search five; deep crawl twenty. Additional page extraction changes the cost.
- Official sources: [Source 1](https://s1.dev/pricing), [Source 2](https://s1.dev/docs/essentials/credits-and-limits)

<a id="gemini-grounding"></a>

### Gemini Google Search grounding

- Eligibility: Eligible Gemini paid-tier project and supported model; billing required.
- Overage: Above the search grant, search fees plus model token fees apply.
- Notes: This is not a zero-cost LLM pipeline: model tokens are billed. Search queries beyond the grant cost $14/1K. Free-tier availability varies by model; do not apply a legacy model allowance to every Gemini model. Default daily cap: 1,500 search queries/project; one prompt can trigger multiple billed queries.
- Official sources: [Source 1](https://ai.google.dev/gemini-api/docs/pricing), [Source 2](https://ai.google.dev/gemini-api/docs/google-search)

<a id="gemini-grounding-free"></a>

### Gemini Flash free-tier grounding

- Eligibility: Eligible free-tier project, supported Flash/Flash-Lite model and region. Not available for Pro on the free tier; verify current model availability.
- Overage: Free-tier limits apply; switching to a paid project changes model and grounding billing. Do not assume 500/day applies to every model.
- Notes: The official tool-pricing table lists a free-tier allowance for Flash/Flash-Lite; Gemini 3+ paid-tier grounding follows a different policy. Model inference has its own free-tier rate limits and data-use terms.
- Official sources: [Source 1](https://ai.google.dev/gemini-api/docs/pricing), [Source 2](https://ai.google.dev/gemini-api/docs/google-search)
